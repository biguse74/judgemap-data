# judgemap-data

시민언론 뉴탐사 데이터 페이지 「판사 이름 찾기」가 쓰는 파일을 둔 곳입니다.
페이지는 https://newtamsa.org/p/judge-map 에 있습니다.

- `data/judgemap.json` — 전국 재판부 구성표(2023-03~2026-07 7개 시점),
  법관 징계, 변호사회 우수법관, 대법원장
- `data/meta.json` — 만든 시각과 집계 규모
- `og.png` — 공유 카드 이미지 (1200×630)

## 자료 출처

- 대법원 「전국 재판부 구성표」 (법원공보 부록)
- 전자관보 대법원 공고 — 법관 징계 (법관징계법 제26조 제2항)
- 법조신문(대한변호사협회) 보도 — 변호사회 법관평가 우수법관

## 담지 않은 것

판결 내용과 판사에 대한 평가는 담지 않았습니다. 공개된 판례는 전체 재판의
일부라 그것으로 한 판사의 판결 성향을 말할 수 없습니다. 이 자료가 답하는
것은 누가 그 자리에 앉아 있는가까지입니다.
